Claude 연결 그림책

Claude에게 새 친구 5명 소개하기

Claude는 혼자서는 노래를 만들거나 게임을 고칠 수 없어요. 하지만 MCP라는 플러그를 꽂아 주면 Suno, Higgsfield, Unity, Jev, Aside와 이야기할 수 있게 돼요. 그림을 보면서 한 단계씩 따라 해 봐요.

Higgsfield ★ Unity ★★ Aside ★★ Suno ★★★ Jev ★★★

별이 적을수록 쉬워요. 처음이라면 Higgsfield부터 해 보세요.

MCP가 뭐예요?

시작하기 전 준비물

Claude 데스크톱 앱claude.ai/download 에서 받아요. 웹사이트보다 앱이 연결하기 쉬워요.
각 앱의 계정Suno, Higgsfield, Unity 계정. 크레딧(이용권)이 있어야 만들 수 있어요.
어른 한 명프로그램 설치와 비밀 열쇠(API 키)는 꼭 어른과 같이 해요.
파이썬 (Python)Unity·Suno·Jev에 필요해요. python.org 에서 받아요. 설치할 때 "Add to PATH"에 꼭 체크!
모든 연결의 마지막 단계는 똑같아요Claude 앱을 완전히 끄고 다시 켜기. 창만 닫으면 안 되고, 화면 오른쪽 아래 작업 표시줄의 Claude 아이콘을 오른쪽 클릭 → 끝내기를 눌러요.

Higgsfield 연결하기

그림과 동영상을 만들어 주는 친구. 공식 MCP가 있어서 제일 쉬워요.

★ 쉬움 · 주소 붙이기
1

설정 열기

Claude 앱 왼쪽 아래 내 이름을 누르고 설정 → 커넥터로 가요.

2

주소 붙여넣기

커스텀 커넥터 추가를 누르고, 이름에 Higgsfield, 주소 칸에 아래 주소를 붙여넣어요.

https://mcp.higgsfield.ai/mcp
3

로그인하고 허용

연결을 누르면 Higgsfield 로그인 창이 떠요. 내 계정으로 로그인하고 허용을 눌러요. API 키는 필요 없어요.

4

부탁해 보기

새 대화를 열고 "Higgsfield로 우주에 사는 고양이 그림 만들어줘"라고 말해 봐요. 처음엔 Claude가 "써도 돼요?" 하고 물어보니 허용을 눌러요.

크레딧이 써져요MCP로 만들 때는 Higgsfield 웹사이트의 무료 생성이 적용되지 않고 내 크레딧이 줄어요.
Claude Code를 쓴다면터미널에 이 한 줄만 입력하고, 처음 쓸 때 브라우저에서 로그인하면 돼요. 
claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp

Unity 연결하기

게임을 만드는 친구. Unity 안에 작은 다리(플러그인)를 놓으면 Claude가 게임 장면을 직접 고쳐 줘요.

★★ 보통 · 자동 설정 버튼
여기서 쓰는 도구무료 공개 프로젝트 MCP for Unity(CoplayDev)를 써요. 미리 Python 3.12 이상과 uv를 설치해 두세요. uv는 PowerShell에 아래 줄을 붙여넣으면 깔려요. 
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
1

패키지 관리자 열기

Unity에서 내 프로젝트를 열고, 위 메뉴 Window → Package Manager를 눌러요.

2

주소로 패키지 넣기

왼쪽 위 + 버튼 → Add package from git URL을 누르고, 아래 주소를 붙여넣은 다음 Add.

https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity

안 되면 프로젝트 GitHub 페이지 README에 적힌 최신 주소를 써요. 버전에 따라 주소 끝부분이 바뀔 수 있어요.

3

자동 설정 누르기

메뉴 Window → MCP for Unity를 열고, Auto-Setup(또는 Claude 옆 Configure) 버튼을 눌러요. Claude 설정 파일을 알아서 써 줘요.

4

Claude 다시 켜고 부탁하기

Claude 앱을 완전히 끄고 다시 켜요. Unity는 켜 둔 채로 "Unity 장면에 빨간 공 하나 만들어줘"라고 말해 봐요.

잘 됐는지 보는 법Unity 창 안에 초록불(연결됨)이 켜져 있고, Claude 대화창의 도구 목록에 unity 도구가 보이면 성공!

Aside 연결하기

대신 웹서핑을 해 주는 AI 브라우저. 연결하면 Claude가 Aside에 열린 웹페이지를 보고 정보를 가져와요.

★★ 보통 · 설정 파일
Aside는 공식 MCP가 있어요Aside 안에 들어 있는 작은 프로그램 aside(CLI)가 MCP 서버 역할을 해요. 그래서 이 프로그램만 깔면 돼요.
1

Aside 설치하고 로그인

어른과 함께 aside.com에서 Aside를 내려받아 설치하고, 내 계정으로 로그인해요.

2

작은 프로그램(CLI) 깔기

Aside의 설정 → 개발자에서 CLI 설치를 눌러요. 이 화면에 aside 프로그램이 있는 위치(경로)가 나오면 적어 두세요.

맥에서는 터미널에 이 줄을 붙여넣어도 돼요.

curl -fsSL https://releases.aside.com/install.sh | bash
3

잘 깔렸는지 확인

PowerShell(맥은 터미널)을 열고 아래를 입력해요. 오류 없이 멈춰 있으면 성공이에요. Ctrl+C로 꺼요.

aside mcp
4

Claude 설정 파일에 적기

Claude 설정 → 개발자 → 설정 편집으로 claude_desktop_config.json을 열고 "aside" 칸을 넣어요. 다른 서버가 있으면 쉼표로 이어 붙여요.

{
  "mcpServers": {
    "aside": {
      "command": "aside",
      "args": ["mcp"]
    }
  }
}

2번에서 경로를 적어 뒀다면 "aside" 대신 그 경로를 넣어요. 연결이 안 될 때 특히 도움이 돼요.

5

다시 켜고 부탁하기

Claude를 완전히 끄고 다시 켜요. Aside는 켜 둔 채로 "Aside로 지금 열린 페이지 내용 요약해줘"라고 말해 봐요.

조심해요Aside는 내가 로그인한 사이트도 볼 수 있어요. Claude가 무언가를 누르거나 보내려고 하면 꼭 내용을 읽어 보고 허용해요.
Claude Code를 쓴다면터미널에 이 한 줄을 입력해요. 
claude mcp add aside -- aside mcp

Suno 연결하기

노래를 만들어 주는 친구. 하지만 Suno는 아직 공식 MCP가 없어요.

★★★ 어려움 · 설정 파일
먼저 꼭 읽어요지금 쓸 수 있는 Suno MCP는 회사가 만든 게 아니라 다른 사람들이 만든 비공식 도구예요. 갑자기 고장 날 수 있고, Suno 이용 약관에 어긋날 수도 있어요. 어른과 함께 약관을 읽어 보고 결정해요. 또 비공식 사이트에 내 비밀번호를 적으면 안 돼요.
1

방법 고르기

A. 브라우저 방식 (suno-mcp): 컴퓨터 안의 브라우저가 내 Suno 계정으로 대신 버튼을 눌러 줘요. 내 크레딧을 써요.

B. API 키 방식 (MCP-Suno): 돈을 내는 외부 API 서비스의 키가 필요해요.

여기서는 A로 설명할게요.

2

명령 창에서 설치하기

시작 메뉴에서 PowerShell을 열고 아래를 한 줄씩 붙여넣어요. (Python 3.10 이상과 Git이 필요해요.)

git clone https://github.com/David-J-Shibley/suno-mcp.git
cd suno-mcp
pip install -e .
playwright install chromium
3

Claude 설정 파일 열기

Claude 앱 설정 → 개발자 → 설정 편집을 누르면 claude_desktop_config.json 파일이 있는 폴더가 열려요. 메모장으로 열어요.

파일 위치: %APPDATA%\Claude\claude_desktop_config.json

4

Suno 칸 적고 저장

아래처럼 적고 저장해요. 실행 명령(command·args)은 예시예요. suno-mcp README에 적힌 실행 방법으로 바꿔 넣어야 해요.

{
  "mcpServers": {
    "suno": {
      "command": "python",
      "args": ["-m", "suno_mcp"]
    }
  }
}
이미 다른 서버가 있다면"mcpServers" 괄호 안에 쉼표(,)를 찍고 "suno" 칸만 이어 붙여요. 괄호 짝이 하나라도 틀리면 전부 안 돼요.
5

다시 켜고 첫 로그인

Claude를 완전히 끄고 다시 켜요. "Suno 크레딧 얼마나 남았어?"라고 물어보면 브라우저 창이 떠요. 그 창에서 내가 직접 Suno에 로그인해요. 한 번 하면 기억해 둬요.

그다음 "신나는 여름 방학 노래 만들어줘!" 해 보세요.

Jev 연결하기

질문에 "몇 점?", "어느 쪽?"처럼 딱 정해진 답을 주는 AI 모델 (TypeSafe Jev).

★★★ 어려움 · API 키
Jev가 맞는지 확인해요"jev"라는 이름으로 찾은 MCP는 TypeSafe의 Jev 모델용 서버(jev-mcp)예요. 공식 문서가 적어서 MCP Market 소개 글을 기준으로 썼어요. 다른 프로그램을 말한 거라면 알려 주세요.
1

비밀 열쇠(API 키) 받기

어른과 함께 TypeSafe 또는 OpenRouter에 가입하고 API 키를 만들어요. API 키는 비밀번호와 같아요. 친구에게 보여 주거나 인터넷에 올리면 안 돼요.

2

서버 내려받기

MCP Market의 jev 페이지에서 GitHub 주소를 찾아 내려받아요. 파이썬 파일 하나로 되어 있어서 따로 설치할 게 거의 없어요. 받은 폴더 위치(예: C:\mcp\jev-mcp)를 기억해요.

3

설정 파일에 적기

Suno 3번처럼 claude_desktop_config.json을 열고 "jev" 칸을 추가해요. 파일 이름과 키 이름은 jev-mcp README에 적힌 대로 바꿔요.

"jev": {
  "command": "python",
  "args": ["C:\\mcp\\jev-mcp\\server.py"],
  "env": { "TYPESAFE_API_KEY": "여기에-내-키" }
}

윈도우 경로는 역슬래시를 두 번(\\) 써야 해요.

4

다시 켜고 물어보기

Claude를 완전히 끄고 다시 켜요. "Jev로 이 문장이 얼마나 기쁜지 점수 매겨줘"처럼 물어봐요.

안 될 때 확인할 것

Claude를 정말 껐나요?작업 표시줄에서 끝내기까지 해야 새 설정을 읽어요.
괄호와 쉼표설정 파일에서 { } 짝이 맞는지, 마지막 칸 뒤에 쉼표가 남아 있지 않은지 봐요.
"서버 연결 끊김" 알림설정 → 개발자에서 빨간 서버를 눌러 로그를 봐요. 보통 python 경로나 설치가 문제예요.
크레딧Suno·Higgsfield는 크레딧이 없으면 만들지 못해요.
